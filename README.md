# Chen Guo — Academic Homepage

Bilingual academic website with Chinese and English pages.

- Chinese: `index.html`
- English: `en.html`
- Shared styles and interactions: `style.css`, `app.js`

The language control in the header switches between the two pages.

## GitHub Pages

Publish from the `main` branch and the repository root. No build step or custom domain is required. Keep `.nojekyll` in the publishing root.

## Updating the website

Update both language pages together and keep their section IDs and publication links consistent. Image paths are relative so the site also works under a GitHub Pages project path.
